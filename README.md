# TimNoi Shabu — ระบบสั่งอาหารหน้าร้าน

เป็น **สองแอป Streamlit แยกกันคนละเว็บ** (คนละ URL, deploy แยกกัน) ใช้ข้อมูล CSV และ
`app_lib.py` ร่วมกัน:

- **`tim.py`** — หน้าร้านสำหรับลูกค้า สแกน QR ที่โต๊ะ → กรอกชื่อ/เลือกโต๊ะ → สั่งอาหารจากเมนู
  (`/`, `/cart`, `/feedback`, `/why-us`)
- **`admin_app.py`** — หลังร้านสำหรับพนักงาน/เจ้าของร้าน จัดการครัว โปรโมชั่น สต็อก/โต๊ะ เมนู
  ยอดขาย ข้อมูลติดต่อ และรีวิว — **แยกเว็บออกจากหน้าร้านลูกค้าโดยสิ้นเชิง** ไม่มีลิงก์เชื่อมจากฝั่ง
  ลูกค้าไปหาเลย (ดูวิธี deploy แยกด้านล่าง)

ข้อมูลเก็บเป็นไฟล์ CSV ในโฟลเดอร์เดียวกับสคริปต์ ไม่ต้องใช้ฐานข้อมูลภายนอก

## เริ่มต้นใช้งาน

```bash
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # แล้วแก้ค่าจริง
streamlit run tim.py          # หน้าร้านลูกค้า
streamlit run admin_app.py    # หลังร้าน (รันคนละ terminal/พอร์ตกัน เช่น --server.port 8502)
```

### แยกหลังร้านเป็นอีกเว็บ (deploy บน Streamlit Community Cloud)

Streamlit Community Cloud ไม่รองรับการ deploy เว็บด้วย IP address ตรงๆ (จะได้ URL แบบ
`ชื่อสุ่ม.streamlit.app` เสมอ) — สิ่งที่ใกล้เคียงที่สุดและทำได้จริงคือ deploy เป็น **แอปที่สอง
แยกต่างหาก** ซึ่งจะได้ลิงก์คนละอันกับหน้าร้านลูกค้า และไม่ถูกลิงก์จากที่ไหนเลยนอกจากคนที่รู้ URL
(หรือจะตั้งรหัสผ่านเพิ่มผ่าน Streamlit Cloud ก็ได้):

1. ไปที่ [share.streamlit.io](https://share.streamlit.io) → "New app"
2. เลือก repo เดิม (`food-order-app`) แต่ตั้ง **Main file path** เป็น `admin_app.py` แทน `tim.py`
3. ใส่ Secrets ชุดเดียวกับแอปแรก (App settings → Secrets) เพราะใช้ข้อมูลร้านเดียวกัน
4. จะได้ URL ใหม่ เช่น `xxxxx.streamlit.app` — ใช้ URL นี้เป็นหลังร้าน ส่วน URL เดิมเป็นหน้าร้าน
   ลูกค้าเหมือนเดิม

ถ้าต้องการ URL แบบ IP จริงๆ (ไม่ใช่ `*.streamlit.app`) ต้องเปลี่ยนไปเช่าเซิร์ฟเวอร์ของตัวเอง
(VPS) แล้วรัน `streamlit run admin_app.py` เองบนนั้น ซึ่งต้องดูแล server/security/HTTPS เอง —
บอกได้ถ้าต้องการให้ช่วยตั้งค่าส่วนนี้เพิ่ม

### ตั้งค่า secrets (จำเป็น)

แก้ไฟล์ `.streamlit/secrets.toml` (ไฟล์นี้ถูก gitignore ไว้แล้ว ห้าม commit):

```toml
[email]
user = "your-shop-gmail@gmail.com"
password = "xxxx xxxx xxxx xxxx"   # Gmail App Password 16 หลัก ไม่ใช่รหัสผ่าน Gmail ปกติ

[admin]
password = "รหัสผ่านสำหรับพนักงานขอเข้าหลังบ้าน"
```

- ถ้ายังไม่ตั้งค่า `[admin]` → หน้าล็อกอินแอดมินจะปิดไว้พร้อมข้อความแจ้งวิธีตั้งค่า
- ถ้ายังไม่ตั้งค่า `[email]` → ระบบส่ง OTP ยืนยันตัวตนไม่ได้ จึงปิดการเข้าสู่ระบบแอดมินไว้ก่อนเพื่อความปลอดภัย (ล็อกอินแอดมินต้องผ่าน OTP ทางอีเมลเสมอ)
- บน Streamlit Community Cloud ให้ไปวางค่าเดียวกันนี้ใน **App settings → Secrets** แทนการอัปโหลดไฟล์

### ปรับสีแบรนด์ / ธีม

แก้ที่ `.streamlit/config.toml` (ไม่ต้องแก้โค้ด/CSS) — ดูคอมเมนต์ในไฟล์ประกอบ

## สรุปสิ่งที่ปรับปรุงจากเวอร์ชันก่อนหน้า

**ดีไซน์**
- เปลี่ยนมาใช้ธีมของ Streamlit (`.streamlit/config.toml`) แทน CSS ที่ฝังในโค้ดเกือบทั้งหมด ทำให้หน้าตาเนียนไปกับคอมโพเนนต์มาตรฐาน ปรับตามอัปเดตของ Streamlit ได้เอง และรองรับทุกอุปกรณ์
- ใช้ไอคอน Material Symbols, `st.metric`/`st.status`/`st.badge` แทนกล่อง HTML ที่เขียนเอง
- มีแถบตะกร้าสินค้าลอยด้านล่าง (sticky cart bar), แบนเนอร์โปรโมชั่นสลับอัตโนมัติ, สถานะครัวแบบเรียลไทม์

**บั๊ก/ความปลอดภัยที่แก้แล้ว**
- **ย้ายรหัสผ่าน/อีเมลจริงออกจากซอร์สโค้ด** ไปไว้ใน `.streamlit/secrets.toml` (เดิมฝังรหัส Gmail App Password และรหัสแอดมินไว้ในไฟล์ .py ตรงๆ)
- เพิ่มวันหมดอายุ + จำกัดจำนวนครั้งที่กรอกผิดให้ OTP และเทียบรหัสผ่าน/OTP แบบ timing-safe
- แก้อาการแอปพังเมื่อโต๊ะเต็มทุกโต๊ะพร้อมกัน (เลือกโต๊ะไม่ได้เพราะตัวเลือกว่างเปล่า)
- ระบบ "รีเฟรชอัตโนมัติทุก 3 วิ" เดิมเป็นโค้ด JavaScript ที่ไม่ทำงานจริง เปลี่ยนมาใช้กลไกของ Streamlit เอง (`st.fragment`) ให้ทุกอุปกรณ์ที่เปิดหน้าค้างไว้เห็นออเดอร์/เมนูใหม่โดยไม่ต้องกดรีเฟรชเอง
- ออเดอร์ใหม่/การรับเงิน/ยกเลิก จะสั่งรีเฟรชให้อุปกรณ์อื่นเห็นทันที (เดิมต้องกดปุ่มรีเฟรชเองที่แอดมิน)
- เพิ่มกล่องยืนยันก่อนลบ (ยกเลิกออเดอร์ ลบเมนู ลบโต๊ะ ลบรีวิว ล้างประวัติล็อกอิน) กันการกดพลาด
- แก้รูปแบนเนอร์/รูปเมนูที่อัปโหลดเป็น JPG แต่ถูกบันทึกเป็น "รูป PNG" ผิดชนิดเสมอ
- แก้การกรองยอดขาย "วันนี้" ที่เดิมใช้การจับคู่ข้อความบางส่วน (เสี่ยงพลาด) เป็นการเทียบวันที่จริง
- เพิ่มโต๊ะ "ไม่จำกัดจำนวนคนพร้อมกัน" (เช่น กลับบ้าน/ซื้อกลับ) กันปัญหาโต๊ะเสมือนหนึ่งโต๊ะถูกจองแล้วบล็อกลูกค้าคนอื่นที่จะสั่งกลับบ้านทั้งหมด
- ปิดการแสดง stack trace ของ Python ให้ลูกค้าเห็น (ความปลอดภัย)

**หลายหน้าแบบมี URL จริง (แทนหน้าเดียวที่สลับเนื้อหาด้วย session state)**
- ฝั่งลูกค้าแยกเป็น `/` (เมนู), `/cart` (ตะกร้า), `/feedback` (ติชม), `/why-us` (ทำไมต้องสั่งที่นี่) — กด F5 / รีเฟรชเบราว์เซอร์แล้วยังอยู่หน้าเดิม, แชร์ลิงก์เฉพาะหน้าได้, กดปุ่มย้อนกลับของเบราว์เซอร์ได้ตามปกติ
- นำทางผ่านแถบเมนูด้านข้าง (sidebar) ของ Streamlit เอง ซ่อนได้/เลื่อนออกมาได้ทุกหน้า (บนมือถือจะยุบไว้อัตโนมัติ กดลูกศรมุมซ้ายบนเพื่อเปิด) แทนปุ่ม "☰ เมนู" popover แบบเดิม — ลดความสับสนที่คำว่า "เมนู" เคยถูกใช้ทั้งความหมาย "เมนูอาหาร" และ "เมนูนำทาง" พร้อมกัน
- เนื้อหา "ทำไมต้องสั่งผ่านหน้านี้?" ย้ายจาก expander ในหน้าแรกไปเป็นหน้าของตัวเอง (`/why-us`) กดดูได้จากปุ่มในหน้าแรกหรือจาก sidebar ได้ทุกหน้า
- ถ้าเข้า `/cart` หรือ `/feedback` ตรงๆ โดยยังไม่ได้กรอกชื่อ/โต๊ะ ระบบจะพากลับไปหน้าเมนูให้อัตโนมัติ
- **หลังร้าน (`admin_app.py`) แยกเป็นเว็บของตัวเองต่างหาก** ไม่อยู่ใน sidebar ของหน้าร้านลูกค้าอีกต่อไป (ดูหัวข้อ "แยกหลังร้านเป็นอีกเว็บ" ด้านบน)
- หน้าตะกร้า: การ์ดแต่ละรายการตัดรูปสินค้าออก (โฟกัสที่ชื่อ/ราคา/จำนวน) และปุ่มเพิ่ม-ลดจำนวนเปลี่ยนเป็นขนาดพอดีเนื้อหาแทนการยืดเต็มความกว้าง ทำให้กระทัดรัดขึ้นและไม่ล้นจอ

**สิ่งที่ยังไม่แตะต้อง (ตั้งใจ)**
- ยังเก็บข้อมูลเป็นไฟล์ CSV เหมือนเดิม (ไม่ได้ย้ายไปฐานข้อมูล) จึงยังมีโอกาสข้อมูลชนกันได้เล็กน้อยหากมีคนสั่งพร้อมกันจำนวนมากมากๆ ในเสี้ยววินาทีเดียวกัน — ถ้าร้านเริ่มมีออเดอร์พร้อมกันเยอะจริงจัง ควรพิจารณาย้ายไปฐานข้อมูลจริง (เช่น SQLite/Postgres) ในอนาคต

## โครงสร้างไฟล์

```
tim.py                          จุดเริ่มแอปหน้าร้านลูกค้า — ตั้งค่าหน้าเว็บ + เชื่อมหน้าลูกค้า (sidebar nav)
admin_app.py                    จุดเริ่มแอปหลังร้าน — คนละเว็บ/คนละ deploy กับ tim.py โดยสิ้นเชิง
app_lib.py                      โค้ดที่ใช้ร่วมกันทั้งสองแอป: ค่าคงที่, อ่าน/เขียน CSV, ส่วนหัวเว็บ, เนื้อหา "ทำไมต้องสั่งที่นี่"
app_pages/menu.py               หน้าแรก (ลูกค้า) — กรอกชื่อ/โต๊ะ + เลือกเมนู (ค้นหา/หมวดหมู่)
app_pages/cart.py               หน้าตะกร้า/ยืนยันสั่งอาหาร (ลูกค้า)
app_pages/feedback.py           หน้าเขียนติชม (ลูกค้า)
app_pages/why_us.py             หน้าอธิบายจุดเด่นของระบบสั่งอาหารออนไลน์ (ลูกค้า)
app_pages/admin.py              หน้าหลังบ้าน (ล็อกอิน OTP + จัดการร้านทั้งหมด) — รันผ่าน admin_app.py เท่านั้น
.streamlit/config.toml          ธีมสี/ฟอนต์/ขอบ ของทั้งสองแอป
.streamlit/secrets.toml         รหัสผ่านจริง (gitignored, ต้องสร้างเอง)
.streamlit/secrets.toml.example ตัวอย่างไฟล์ secrets
requirements.txt                dependency ที่ต้องติดตั้ง
logo.png                        โลโก้ร้าน
```

ไฟล์ `*.csv`, `uploaded_images/`, `banner_images/`, `refresh_signal.txt` เป็นข้อมูลที่แอปสร้างเองตอนรัน (ถูก gitignore ไว้แล้ว)
